# VSCode/Windsurf/Cursor 推荐插件

以下是我使用的插件（主要作为 TypeScript 开发者），但并非全部：

- Cline
- Code Spell Checker（代码拼写检查器）
- CodeMetrics（代码度量）
- Docker
- ESLint
- Foam（即将推出相关视频）
- Jest Runner（firstris）
- Markdown Preview Mermaid Support（Markdown Mermaid 预览支持）
- Monokai Charcoal high contrast（超爱这些主题！）
- Playwright Test for VSCode（如果使用 Playwright 进行端到端测试）
- Prettier - Code formatter（代码格式化工具）
- Prettier - ESLint
- SQLite

我也在使用 GoLang、Python 和 C# 时使用相关插件。
